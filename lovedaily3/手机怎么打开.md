# 手机打不开链接 —— 原因和三个解决办法

## 为什么打不开

我查了那个分享链接的 DNS：

```
058246b814974dfc8ae64331cf4de5ba.tc-nanjing.share.codebuddy.woa.com
  → 9.134.135.132
```

**`9.x.x.x` 是内网地址段**，`woa.com` 是公司内部域名。

所以：

| 设备 | 网络 | 结果 |
|---|---|---|
| 你的 Mac | 公司网络 | **能打开**（能路由到 9.x） |
| 你的 iPhone | 手机流量 / 家里 WiFi | **打不开**（到不了 9.x） |

不是链接失效，是**那个域名本来就只在公司网络内可达**。

---

## 方案 A：单文件版（最省事，推荐先用这个）

**`dark-standalone.html`** —— 整个 App 打包成一个文件，118KB，**不需要任何服务器**。

### 怎么用

1. 用**微信发给自己**（文件传输助手），或用 **AirDrop 隔空投送**到 iPhone
2. 手机上点开 → 选**「用 Safari 打开」**
3. 分享按钮 → **添加到主屏幕**

桌面出现图标，点开全屏运行。

### 能用什么

| 功能 | 状态 |
|---|---|
| 任务勾选、三环动画 | ✅ |
| Dark 的提醒与夸赞、thought process | ✅ |
| 对话页 | ✅ |
| **真实天气、温度、地点** | ✅ 实测拿到 32°/深圳/体感 36° |
| 计划页周/月/年 | ✅ |
| 数据保存（关掉再开还在） | ✅ |
| 全屏无地址栏 | ✅ |
| **系统通知（锁屏弹出）** | ❌ |

**只损失系统通知**，因为 `file://` 下无法注册 Service Worker。临期提醒会以 App 内提示的形式出现。我已经把「我的」页里的通知按钮**置灰并写明原因**，不会让你点了没反应。

天气能用是我特意验证过的——Open-Meteo 返回通用跨域头，`file://` 下也放行。

## 方案 B：局域网（在公司时用，能测系统通知）

```bash
cd /Users/gogofeng/WorkBuddy/2026-08-12-15-44-59/app/dark
bash serve-lan.sh
```

它会打印一个地址，比如 `http://10.2.151.73:8123`，手机在**同一个 WiFi** 下用 Safari 打开。

- 走 http 协议 → Service Worker 能注册
- 但 **iOS 的通知权限要求 https**，所以通知仍然受限
- **关掉终端窗口手机就打不开了**

适合快速在真机上过一遍完整交互，不适合日常用。

---

## 方案 C：真公网 HTTPS（想要系统通知就走这条）

只有这条能让通知真正工作。用 Cloudflare Pages，免费，不用命令行：

1. 打开 **https://pages.cloudflare.com** ，注册/登录
2. 选 **Create a project → Upload assets**
3. 把 **`app/dark` 这个文件夹**整个拖进去（`dark-standalone.html` 可以不传）
4. 点 Deploy，得到一个 `https://xxx.pages.dev` 的地址

然后手机 Safari 打开那个地址 → 添加到主屏幕 → **我的 → 任务临期提醒 → 授权**。

这条路顺便解决另一件事：你要接 DeepSeek 的话，**Worker 也在 Cloudflare 上**，同一个账号就够了。

## 怎么选

```
现在就想在手机上用      → 方案 A（微信发单文件版）
想试系统通知，且在公司   → 方案 B
要长期用、要锁屏提醒     → 方案 C
```

**建议：先 A 用起来，觉得顺手了再花 5 分钟做 C。**

## 验证情况

单文件版我用 `file://` 协议在真实浏览器里跑过 **27 项检查**，全过：

- 6 个页面、9 条任务、三环联动、夸赞、thought process 四拍展开
- **真实天气 32°/深圳/体感 36.2°/8 小时降雨概率**
- 对话回复符合人设、计划页三维度、刷新后状态保持
- 通知按钮正确置灰并说明原因
- 零致命错误

其中天气一项我**特意关掉了 Chrome 的宽松开关重测一遍**（`--allow-file-access-from-files` 是 Safari 没有的），严格策略下仍拿到 31.7°C，确认不依赖任何特殊设置。
