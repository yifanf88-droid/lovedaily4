# 念念日程 · Dark 动态故事线 + 智能关心引擎

## ✅ 方案 B 已完成

### 核心功能

1. **Dark 动态故事线**：每天刷新新事件，有连贯性（不是随机的）
2. **Dark 智能关心引擎**：根据天气、温度、你的完成率动态生成关心任务

## 🎯 功能 1：Dark 动态故事线

### 设计理念

**问题**：旧版 Dark 的 5 个日程是硬编码的，每天看到的都一样，失去了"他也在工作"的真实感。

**解决方案**：
- 预设 **3 条故事线模板**（跨境并购案、IPO 路演准备、B轮融资谈判）
- 每 **3 周自动切换**一个故事线（保持连贯性）
- 每天的任务时间 **随机偏移 ±15 分钟**（基于日期种子，同一天永远一致）
- 周末使用周五的任务（他周末也在工作）

### 切换逻辑

```javascript
// 每 3 周切换一个故事线
var weekOfYear = Math.floor(dayOfYear / 7);
var storyIndex = Math.floor(weekOfYear / 3) % 3;

// 示例：
// 第 1-3 周  → 跨境并购案
// 第 4-6 周  → IPO 路演准备
// 第 7-9 周  → B轮融资谈判
// 第 10-12 周 → 跨境并购案（循环）
```

### 时间偏移

```javascript
// 每天任务时间随机偏移 ±15 分钟（基于日期种子）
var offset = (hash(dateStr + ':' + taskIndex) % 30) - 15;
// 07:30 → 可能变成 07:22 或 07:43（同一天永远一致）
```

**效果**：
- ✅ 每天看 Dark 页面，他的任务都有变化（时间微调）
- ✅ 每 3 周故事线切换，长期使用不会腻
- ✅ 任务时间基于日期种子生成，**同一天多次查看结果一致**

## 🎯 功能 2：Dark 智能关心引擎

### 设计理念

**问题**：旧版 Dark 的关心任务是固定的（"今天只喝一杯咖啡"），不会根据实际情况变化。

**解决方案**：
- 根据 **天气、温度、完成率、时间** 动态生成关心任务
- 规则库：if-then 逻辑（下雨 → 带伞，高温 → 多喝水...）
- 自动添加到"他为我加的"环（查看今天时触发）

### 关心规则库

#### 规则 1：天气关心（优先级最高）

| 条件 | 任务 |
|---|---|
| 天气含"雨" | "今天会下雨，记得带伞" |
| 温度 > 32°C | "今天 35 度，多喝水" |
| 温度 < 5°C | "今天很冷，多穿点" |

#### 规则 2：完成率关心

| 条件 | 任务 |
|---|---|
| 晚上 8 点后 + 完成率 < 30% | "别给自己太大压力" |

#### 规则 3：健康关心

| 条件 | 任务 |
|---|---|
| 今天没有身体任务 + 还不到晚上 10 点 | "今天记得动一动" |

#### 规则 4：睡眠关心

| 条件 | 任务 |
|---|---|
| 晚上 11 点后 | "该睡了" (时间：23:30) |

### 去重机制

```javascript
// 已存在的关心任务不重复添加
var existingIds = tasks.map(function (t) { return t.id; });
cares = cares.filter(function (c) { return existingIds.indexOf(c.id) === -1; });
```

**效果**：
- ✅ 天气变化 → 关心任务自动适配
- ✅ 完成率低 → 晚上出现鼓励任务
- ✅ 没有运动 → 自动提醒
- ✅ 熬夜 → 催你睡觉
