# 念念日程 · 循环计划功能

## ✅ 功能完成

### 核心能力

用户可以创建**循环计划**，系统会自动在匹配的日期生成任务到今天页。

**使用场景**：
- 每周固定的活动（健身、会议、课程...）
- 每月固定的事项（还款、复盘、体检...）
- 有期限的阶段性计划（为期3个月的减肥计划）

---

## 🎯 使用方法

### 1. 添加循环计划

**步骤**：
1. 切换到**计划页**
2. 点击左上角**"循环计划"**选项卡
3. 点击右下角 **FAB（+）**
4. 填写表单：
   - **要做什么**：计划标题（例如"健身房锻炼"）
   - **时间**：可选，例如 18:00
   - **归到哪个环**：正事 / 身体
   - **重复周期**：每周 / 每月
   - **在哪几天**：
     - 每周：勾选周几（可多选）
     - 每月：输入日期，逗号分隔（例如 1,15）
   - **持续时间**：开始日期 / 结束日期（可选）

### 2. 查看循环计划

在**计划页 → 循环计划**选项卡查看所有进行中的计划：
- 显示计划标题、周期、时间
- 显示持续时间
- 可删除计划

### 3. 自动生成任务

**今天页**会自动根据循环计划生成当天的任务：
- 每天打开今天页时自动检查
- 匹配当天日期的计划会自动出现在任务列表
- 任务标记为"来自计划"（`fromPlan` 字段）

## 🛠️ 技术实现

### 数据结构

```javascript
S.plans = [
  {
    id: 'plan1723456789',
    title: '健身房锻炼',
    ring: 3,  // 1=正事, 3=身体
    repeat: 'week',  // 'week' | 'month'
    days: [2, 4, 6],  // 周：0-6（0=周日） | 月：1-31
    start: '2026-08-14',
    end: '2026-11-14',
    time: '18:00'
  }
];
```

### 核心函数

#### 1. `planMatches(plan, dateStr)` — 判断日期是否匹配计划

```javascript
function planMatches(plan, dateStr) {
  var d = parseDate(dateStr);
  if (!d) return false;
  
  // 检查日期范围
  if (plan.start && dateStr < plan.start) return false;
  if (plan.end && dateStr > plan.end) return false;
  
  // 检查重复规则
  if (plan.repeat === 'week') {
    var dayOfWeek = d.getDay();  // 0=周日, 1=周一...
    return plan.days.indexOf(dayOfWeek) > -1;
  } else if (plan.repeat === 'month') {
    var dayOfMonth = d.getDate();
    return plan.days.indexOf(dayOfMonth) > -1;
  }
  return false;
}
```

#### 2. `materializePlans(dateStr)` — 生成指定日期的计划任务

```javascript
function materializePlans(dateStr) {
  if (!S.plans) S.plans = [];
  var tasks = [];
  
  S.plans.forEach(function (plan) {
    if (planMatches(plan, dateStr)) {
      tasks.push({
        id: 'plan-' + plan.id + '-' + dateStr,
        time: plan.time || '',
        title: plan.title,
        ring: plan.ring,
        done: false,
        fromPlan: plan.id  // 标记来源
      });
    }
  });
  
  return tasks;
}
```

#### 3. `renderPlanList()` — 渲染计划列表

```javascript
function renderPlanList() {
  if (!S.plans) S.plans = [];
  var active = S.plans.filter(function (p) {
    var today = todayStr();
    return (!p.end || p.end >= today);  // 未过期的计划
  });
  
  if (active.length === 0) {
    $('#planList').innerHTML = '<div class="empty">还没有循环计划。</div>';
    return;
  }
  
  // 渲染每个计划的卡片...
}
```

### 触发时机

**在 `go('today')` 时自动生成计划任务**（第 1858-1864 行）：
```javascript
if (name === 'today') {
  // ...
  /* 循环计划任务生成 */
  var planTasks = materializePlans(S.view);
  planTasks.forEach(function (t) {
    if (existingIds.indexOf(t.id) === -1) {
      tasks.push(t);
    }
  });
  // ...
}
```

### 去重机制

- 任务 ID 格式：`plan-<planId>-<dateStr>`
- 例如：`plan-plan1723456789-2026-08-15`
- 同一天不会重复生成相同计划的任务
