# 念念日程 · 日期选择器功能

## ✅ 已完成的功能

### 多日任务系统 + 日期选择器

**核心功能**：
- ✅ 可以查看**过去**的日程（回顾历史）
- ✅ 可以为**未来**添加日程（提前规划）
- ✅ **Dark 的关心任务只在"今天"显示**（他不会给未来加日程）
- ✅ 每天的任务独立存储，跨天不会丢失

---

## 🎯 使用方法

### 1. 切换日期

**点击首页顶部日期**（例如"8月14日"）→ 弹出原生日期选择器

<img width="400" alt="日期选择器" src="https://via.placeholder.com/400x300/1a1a1a/ffffff?text=点击日期+→+选择器弹出">

- 选择**过去日期**：查看那天完成了哪些任务
- 选择**未来日期**：提前添加下周、下个月的任务

### 2. 添加任务到指定日期

**步骤**：
1. 点击日期，选择目标日期（例如"8月20日"）
2. 点击右下角 FAB（+）添加任务
3. 任务会自动保存到 8月20日

**示例**：
- 今天是 8月14日（周五）
- 我想提前安排下周三（8月19日）的会议
- 点击日期 → 选择 8月19日 → 点击 + → 添加"10:00 团队周会"
- 到了 8月19日，这个任务会自动出现在今天页

### 3. Dark 的关心规则

**只在"今天"显示**：
- 当你查看**今天**（8月14日）→ Dark 的关心任务会显示在"他为我加的"环
- 当你查看**未来**（8月20日）→ "他为我加的"环**不显示**（Dark 不会提前关心）
- 当你查看**过去**（8月10日）→ "他为我加的"环**不显示**（历史关心已归档）

**原因**：Dark 的关心是基于**当天的天气、温度、你的状态**实时生成的，所以只在"今天"有意义。

## 🛠️ 技术实现

### 数据结构升级

**修改前（单日模式）**：
```javascript
S = {
  day: '2026-08-14',  // 今天的日期
  tasks: [...]        // 所有任务都在这里
};
```

**修改后（多日模式）**：
```javascript
S = {
  day: '2026-08-14',   // 今天的日期（真实日期）
  view: '2026-08-20',  // 当前查看的日期（可以是过去/未来）
  days: {
    '2026-08-14': [...],  // 8月14日的任务
    '2026-08-15': [...],  // 8月15日的任务
    '2026-08-20': [...]   // 8月20日的任务（提前添加的）
  }
};
```

### 核心函数

#### 1. `dayTasks(dateStr)` — 获取指定日期的任务
```javascript
function dayTasks(dateStr) {
  if (!S.days[dateStr]) S.days[dateStr] = [];
  return S.days[dateStr];
}
```

#### 2. `renderDate()` — 日期显示（可点击）
```javascript
function renderDate() {
  var d = parseDate(S.view) || new Date();
  var isToday = S.view === todayStr();
  
  $('#dbig').innerHTML = '<button id="dateBtn">8月14日 ▾</button>';
  // 点击后触发日期选择器
}
```

#### 3. `renderTasks()` — 任务列表（支持多日）
```javascript
function renderTasks() {
  var tasks = dayTasks(S.view);  // 获取当前查看日期的任务
  var isToday = S.view === todayStr();
  
  // Dark 的关心任务只在"今天"显示
  if (g.r === 2 && !isToday) return;
  
  // 渲染任务列表...
}
```

### 向后兼容

旧版数据会自动迁移：
```javascript
// load() 函数里的迁移逻辑
if (!S.days) {
  S.days = {};
  S.days[S.day] = S.tasks;  // 把旧的 tasks 迁移到 days[today]
}
```
