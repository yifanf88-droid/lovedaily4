### 2. 关键Bug修复
**问题**: 线上版有两个 `$()` 函数定义冲突
```javascript
// 原代码（错误）
function $(s) { return document.querySelector(s); }
function $(s) { return [].slice.call(document.querySelectorAll(s)); }
// ↑ 后者覆盖前者，导致 $('#fab') 返回数组而不是元素
```

**修复**: 改为标准的 `$` 和 `$$` 分工
```javascript
function $(s) { return document.querySelector(s); }        // 单选
function $$(s) { return [].slice.call(document.querySelectorAll(s)); }  // 多选
```

并把所有多选场景改成 `$$`：
- `$('.screen').forEach` → `$$('.screen').forEach`
- `$('.tab').forEach` → `$$('.tab').forEach`
- `$('.pv').forEach` → `$$('.pv').forEach`
